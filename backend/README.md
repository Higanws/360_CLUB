# Backend (NestJS)

API Club360. Documentación: **[../docs/desarrollo.md](../docs/desarrollo.md)** y **[../docs/base-de-datos.md](../docs/base-de-datos.md)**.

```bash
npm install
npm run start:dev    # desarrollo
npm run build
npm run db:seed      # reset BD: schema + seed SQL
npm test
```

Prefijo HTTP: `/api`. Persistencia: TypeORM → MariaDB/MySQL.
